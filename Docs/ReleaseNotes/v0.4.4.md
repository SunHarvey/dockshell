# v0.4.4

SSH 断线后，可在原终端按 Enter，或点击提示条里的“重新连接”，继续连接该服务器。

- 支持主键盘 Return 和数字键盘 Enter，断线提示条显示按键说明。
- 新增醒目的鼠标重连按钮；关闭错误详情后仍保留重连提示与按钮。
- 重连在原标签内进行，使用该标签的服务器配置重新认证，建立新的远端 Shell。
- 按键重连仅在断线终端获得焦点时触发。已连接终端的 Enter、密码输入框和其他标签继续使用各自的输入处理。
- 更新 README、连接恢复与 GitHub Actions 发布文档。

从下方 **Assets** 下载 `DockShell-0.4.4-arm64.dmg`，打开后将 **DockShell.app** 拖到 **Applications（应用程序）** 安装。
