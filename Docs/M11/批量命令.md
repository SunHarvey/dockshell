# M11：独立批量命令栏

更新日期：2026-10-31。本页记录 **0.2.0 / build 21** 的开发与验收；相关功能纳入 **v0.3.0 / build 22**，见 [版本说明](../ReleaseNotes/v0.3.0.md)。发布不会自动替换本机已安装的应用。

用户确认采用独立命令栏：输入后执行，发送到全部已连接的 SSH 标签。终端右上角的日志记录图标按要求删除；默认日志记录继续生效，状态、开始/暂停和导出入口保留在终端右键菜单中。

## 使用

1. 退出旧版 DockShell 后，在仓库根目录运行 `sh Scripts/run.sh`。
2. 打开需要操作的 SSH 会话。可以使用普通标签、左右并列或上下堆叠。
3. 选择右上角 **⋯ 更多操作 → 批量执行命令**，工作区底部展开命令栏。默认不显示，不增加顶部图标。
4. 在命令栏输入一行命令，例如 `pwd`、`ls -la` 或 `printf '中文🙂\n'`。
5. 按回车或点击**执行到全部**。顶部显示已连接/已打开数量，下方显示已排队、跳过和队列已满数量；展开结果可查看各标签的编号、名称与状态。
6. 点击命令栏的 **×** 关闭，或在输入框按 Escape。关闭后恢复当前标签的正常焦点，空间归还终端；认证未完成时不强制切换到终端。

至少一个会话已排队时清空输入框，方便输入下一条命令；全部未发送或校验失败时保留文本供修改。关闭命令栏或关闭工作区会清空草稿与上次发送记录，不保存命令历史。批量栏展开时暂停终端的自动聚焦，因此所选连接重连完成不会抢走正在编辑的草稿；仍可主动点击某个终端单独操作。

## 精确行为

| 场景 | 处理 |
|---|---|
| 多个已连接标签 | 每条连接各收到一次相同 UTF-8 命令，并追加一次终端回车 |
| 同一个保存会话打开多次 | 每个独立连接分别发送，不按服务器名或配置 ID 去重 |
| 后台标签、分屏 | 同样参与，与当前选中标签或分屏方向无关 |
| 等待主机指纹或密码/口令认证 | 跳过，绝不将命令作为认证输入 |
| 连接中、断线、失败或已关闭标签 | 不发送、不自动连接或重连；仍打开的标签在结果中显示跳过原因 |
| 一个会话输入队列已满 | 只拒绝该会话，其他可用连接继续接收；结果明确列出该项 |
| 新开、关闭、重排标签 | 每次执行按点击时的标签集合和顺序固定目标；下一次才采用后续变化 |
| 发送后断线或重连 | 不自动重试、不重放旧命令到新连接 |
| 普通终端输入 | 仍只发给该终端，不广播每个按键、鼠标事件或终端协议回复 |
| 本机 shell、SFTP | 不参与，范围是用户确认的全部已连接 SSH 标签 |

“已排队”表示命令进入本地该连接的有界输入队列，不表示服务器已经执行成功。后续网络异常由对应终端的连接状态和错误提示反映；命令是否成功以各终端输出为准。不同连接独立运行，不保证同一时刻开始，也不能提供跨服务器事务。

请在目标终端都回到 shell 命令提示符时使用。处于 vim、top、sudo 提示或其他交互程序时，输入会由当前程序处理；应用不会先发送 Ctrl-C、退出程序或擅自清空已有输入。

每次提交最多 **16 KiB UTF-8**，按字节计算。原始命令保留前后空格、中文、emoji 与制表符，不添加本机 shell 包装或二次展开。含换行或其他终端控制字符的内容会明确拒绝；可在单行内使用自己需要的 `;`、`&&` 等 shell 语法。

命令不写入设置、数据库、报错信息或发送报告。服务器打印、回显的文字仍属于该连接正常输出；若开启终端日志，会依照原有日志规则记录。

## 验证

```sh
sh Scripts/test-batch-commands.sh
sh Scripts/test-batch-commands.sh release
```

默认测试应用位于 `Build/M11.noindex`，不安装或登记测试应用，不使用个人服务器、凭据或偏好。

- 模型检查：单行与 UTF-8 容量校验、恰好一次回车、同配置独立连接、普通输入隔离、主机/密码认证跳过、连接中/断线跳过、后台输出、排序/分屏、单目标队列满、关闭标签、重连不重放及命令栏状态清理。
- 原生 UI 检查：中英文命令栏实际输入中文与 emoji，测试窗口内原生鼠标点击发送和 Return 各发送一次，成功后清空草稿，所选连接重连后仍保持输入焦点，在 360、220、180pt 宽度下检查输入区域，实际点击关闭后重新打开不恢复旧命令。
- 实际执行检查：两个独立、私有 HOME 的 `zsh -f` PTY，输入通过真实生产 SSH 控制器和批量端口送达，确认相同中文命令在两条 shell 中各执行一次，并输出各自不同的工作目录。此处用本机 PTY 验证交互输入与执行，不冒充真实 Linux SSH 验收。

脚本同时要求 M11 专项完成和总验证完成标记，防止环境开关遗漏时误把普通回归当作专项通过。

本轮 Debug / Release 批量专项、中英文实际按钮/回车、两个隔离 shell 执行均通过；原有 Debug / Release 默认回归、Debug 完整 UI 与应用搬迁通过，日志接入和字体/模式/真实 vim/top 专项通过。焦点规则统一后，再次通过两种配置的批量专项和原生工作区/字体回归。工作流 YAML、脚本语法和完整文件链接检查通过；未运行远端 Actions。

手工验收时可先连接两台测试服务器，确认都在命令提示符后发送 `pwd`；再关闭或断开其中一条，核对下一次发送的排队/跳过数量和对应输出。真实输入法候选交互、个人服务器和 macOS 14 实机仍需目标环境验收。
