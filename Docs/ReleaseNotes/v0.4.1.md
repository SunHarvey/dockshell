# v0.4.1

将保存和导入的连接配置统一称为“服务器”，让首页与导入流程使用一致的名称。

- 首页统一显示“所有服务器”“已保存的服务器”和“搜索服务器”。
- 新建、编辑、删除、分组、系统菜单、SSH / CSV 导入预览，以及认证和错误提示的中英文文案同步更新。
- 服务器配置模型、编辑与导入类型、仓储及相关文件同步更名，README 和使用指南同步调整。
- 已有服务器配置、分组、私钥引用和 Keychain 凭据继续兼容；升级后可直接使用。
- 保留 SSH / CSV 导入、多标签与分屏、SFTP、批量命令、终端日志、本机 Shell 和即时设置。
- 安装包统一命名为 `DockShell-版本号-架构.dmg`，文件名不含构建号或 `local-preview`。

从下方 **Assets** 下载 `DockShell-0.4.1-arm64.dmg`，打开后将 **DockShell.app** 拖到 **Applications（应用程序）** 安装。
