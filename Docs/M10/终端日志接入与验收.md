# M10.1：终端日志接入与验收

更新日期：2026-10-31。本页记录 **0.2.0 / build 20** 的接入结果，相关功能纳入 [v0.3.0 / build 22](../ReleaseNotes/v0.3.0.md)。此前 v0.2.0 / build 19 不包含本功能；源码和发布不会自动替换 `/Applications` 中的应用。

## 使用方式

1. 从本轮源码启动应用：在仓库根目录运行 `sh Scripts/run.sh`。
2. 打开 SSH 连接或本机终端，默认自动记录；在终端右键菜单查看记录状态，不增加底部栏。后续 build 21 已按用户反馈删除右上角日志图标，见 [批量命令与角标调整](../M11/批量命令.md)。
3. **⌘, → 设置**可开关终端日志，调整每连接容量，点击保存后作用于所有已打开终端，包括后台标签。默认 **5 MB = 5,000,000 字节**，可选 1–100 MB。
4. 在终端内容区域右键，选择**导出终端日志…**，选择本机保存位置。导出 `.log` 是 UTF-8 纯文本，可用文本编辑器打开。
5. 右键菜单也可**暂停日志记录 / 开始日志记录**，只影响当前连接；重新连接或改变设置中的全局开关后恢复全局偏好。

关闭记录不会删除已保留内容；连接断开后，只要标签还在，仍可右键导出。导出、取消导出或导出失败不会停止正在进行的记录。已有同名文件不会被覆盖，会给出明确提示，请另选文件名。

## 保留规则

| 情况 | 行为 |
|---|---|
| 容量 | 每次连接拥有独立预算；同一服务器的两个连接分别计算 |
| 超限 | 删除最早的 UTF-8 分段，保留最近内容及“较早内容已删除”说明；不会因长时间输出无限增加单连接文件大小 |
| 缩小容量 | 保存后立即淘汰最早内容；已导出的文件不受影响 |
| 扩大容量 | 增加之后可保留的内容，不能恢复已淘汰文字 |
| vim / 备用屏幕 | 不记录备用屏幕画面，保留进入、退出的时间标记 |
| 普通输出 | 基于当前终端解析器提取可显示文字，去除颜色等控制序列，保留中文、emoji 和软折行逻辑 |
| 暂停后恢复 | 不补录暂停期间内容；暂停时已有的半行会略过至下一次硬换行，并写入说明标记 |
| 导出时点 | 先在有序管道中固定内容和未换行尾部，再显示保存窗口；窗口打开后的新输出不混入本次文件 |
| 重连 | 创建新的独立连接日志，旧日志完成收尾后关闭；不把不同连接的内容混在一起 |
| 关闭标签 / 正常退出 | 先收集已解析的未换行尾部，再排队写完结束标记并关闭文件；应用退出等待收尾 |
| 错误 | 中文或英文可读提示；存储、容量队列或提取出现错误时明确停止记录，终端输入输出仍继续 |

日志上限计算 UTF-8 内容及标记字节，文件系统目录、元数据和块分配不包含在此数值中。按小段淘汰，因此实际保留量可能略小于上限；一次后台追加期间最多临时多一个 64 KiB 分段。未换行长行在内存中也受容量约束，不无限增长。容量不是所有历史连接加总的配额。

缓存通过系统目录 API 放在当前用户的 `Library/Logs/DockShell/<连接 UUID>/` 中，目录权限 0700、文件权限 0600。导出采用同目录临时文件与独占发布，失败清理临时文件；不会覆盖已有文件或跟随最终目标符号链接。

已结束连接的分段缓存保留在磁盘上。本轮没有历史日志浏览器、启动后恢复导出或全局历史清理入口；已关闭标签的日志需从此前导出的副本查看。若需要整理缓存，应先退出应用，再处理该日志目录；不要删除会话数据库或 Keychain 项目。

SSH 认证成功后才开始记录终端通道；认证弹窗中的密码、私钥口令和原始按键没有接入日志。终端程序主动打印、服务器回显的文字仍属于输出，可能包含敏感信息，导出前应自行检查。普通日志不能还原任意光标重绘的全部编辑历史，不能用来恢复 vim 文件，也不是终端录像。不使用备用屏幕的 `top` 版本按普通输出处理。

## 自动验证

在有图形桌面的 macOS 上运行：

```sh
sh Scripts/test-terminal-logging-integration.sh
sh Scripts/test-terminal-logging-integration.sh release
```

默认打包到 `Build/M101.noindex`；不安装应用，不向个人会话、服务器、Keychain 或正式偏好写入数据。偏好迁移使用随机隔离 suite；文件在临时 0700 目录中；真实 shell 为独立 HOME 的 `zsh -f`；vim 禁止个人配置、插件、viminfo 和交换文件。

覆盖范围：旧偏好兼容、默认开启与容量持久化，真实文件轮转与独立配额，容量立即缩小/扩大，UTF-8 边界、0600 导出、同名/符号链接拒绝与临时文件清理，生产 SSH 控制器和原生终端的暂停/恢复、后台输出、重连、未换行收尾、日志错误隔离，真实本机 PTY 与 vim 的备用屏幕策略及运行时字体更新；另有受控慢存储测试验证队列过载时不丢弃此前已接收的日志。

原生菜单成功导出链路使用可替换的位置选择协议选定临时文件，文件写入走实际存储。实际 NSSavePanel 的显示、命名、本地化与取消由真实本机终端验证。macOS 的跨进程文件面板不允许测试直接调用 `ok:`，因此系统面板内**实际鼠标点击保存**仍需下列手工验收；不将自动化协议替身当作这一项已经通过。

20,000 行中文和 emoji 共 1,640,014 输入字节的负载检查，会精确比较全部解析后文本，证明不受 10000 行滚屏历史限制，并同时测量主线程心跳间隔。实际耗时与最大间隔由脚本打印，属于本机实测，不代表所有硬件的保证。

## 手工验收

- 从源码打开应用，在本机终端执行 `printf '日志测试 中文🙂\n'`，右键导出，实际点击系统保存按钮，打开文件核对内容。
- 让保存窗口保持打开，再产生一些输出；本次导出应只包含打开窗口前的快照，下一次导出才包含新内容。
- 运行 vim，编辑后退出，再输出普通文字；日志应只有备用屏幕进出时间与前后普通输出。
- 设置关闭日志并保存，输出测试文字，再开启；关闭期间内容不得出现在新导出中。调整容量后立即生效，重启后偏好仍保留。
- 同时打开两个 SSH 标签，切换、拖动和左右并列/上下堆叠；分别导出，内容必须属于各自连接。重连后为新日志。
- 在授权 Linux 服务器上手动重复以上操作；本轮自动化没有访问个人服务器。

macOS 14 实机、真实中文输入法候选交互、实际睡眠和终止进程导致的异常恢复不因本轮通过而视为已完成。强制结束进程无法保证未收尾尾部写入；正常关闭和退出有等待机制。
