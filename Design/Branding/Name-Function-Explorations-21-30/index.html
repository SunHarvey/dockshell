DOCKSHELL / NAME × FUNCTION

名字与功能 · 21–30

Dock：停靠、连接、会话归位。Shell：命令、光标、远程终端。
每款只选择一个重点，把名字或已有功能融入图形。点击图片查看原图。

命令泊位

↗

Dock + Shell

D 形泊位接住命令提示符，把 Dock 与 Shell 合成一个符号。

22

会话归港

↗

多标签 + Dock

三个独立会话停靠在同一底座，对应多标签管理。

23

DS 通道

↗

名字首字母 + SSH

D 与 S 共用一条连续通路，表达本地与远端之间的连接。

24

Shell 开口

↗

Shell + 命令

两片贝壳之间露出命令箭头，将 Shell 的字面与终端含义连接起来。

25

双端相接

↗

SSH 连接

两个独立端点在中间接合，表达 SSH 的本地端与远端。

26

等分 D

↗

D + 等分分屏

D 的内部由两个等大视窗构成，对应横排、竖排的等分终端。

27

命令字标

↗

名字 + 终端字标

直接使用 DockShell 名字，以停靠基线和命令光标建立终端识别。

28

Shell 流路

↗

S + 双向通信

S 由两段互通的折线路径组成，表达命令输入与远端输出。

29

主机印记

↗

D + 主机身份核验

稀疏的 D 形纹路暗示主机指纹与首次连接确认。

30

停靠接口

↗

Dock + 连接就绪

d 形接口与进入的光标块相互咬合，表达连接建立和命令就绪。
