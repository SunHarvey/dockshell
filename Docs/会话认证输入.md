# 会话认证输入

本文说明当前源码中的私钥粘贴、密码与口令显示切换，以及终端布局名称。安装包是否包含这些改动，以对应 Release 的说明为准。

## 选择文件或粘贴私钥

在新建或编辑会话中选择 **私钥** 认证后，可以切换 **选择文件** 和 **粘贴私钥**：

- 选择文件保留原文件，仅保存文件书签；DockShell 不复制或删除用户选择的外部私钥。
- 粘贴私钥需要包含完整的开始、结束标记。点击保存前，内容只在表单内存中；取消不会创建私钥文件。
- 保存时先检查会话字段和私钥容器，再生成独立的托管文件。支持范围沿用已有 OpenSSH / PEM 检查，输入上限为 1 MiB；PuTTY `.ppk`、不支持的封装或损坏内容会显示明确错误。

托管目录由系统 Application Support API 定位，通常位于当前用户的 `Library/Application Support/DockShell/PrivateKeys`。目录权限为 `0700`，每个随机 UUID 命名的 `.key` 文件权限为 `0600`，仅当前用户可访问。程序不写死用户主目录。

私钥文件保留粘贴内容原有的加密状态，只规范 Windows 换行和首尾空白；DockShell 不额外加密这个文件。私钥口令和密码继续单独保存在 Keychain。SQLite 仍只保存非秘密会话字段、凭据标识和文件书签，不保存私钥正文；这些改动无需更改会话数据库结构。

## 文件生命周期

导入采用独立新文件，不覆盖先前私钥。保存失败时，只有在数据库能确认本次文件尚未被引用后才回收；提交结果不明确时保留文件，避免删除已经保存成功的私钥。

替换私钥、删除会话或更换认证方式后，失去引用的托管文件在 **下次应用启动** 时清理。清理先取得会话仓库的独占访问，再依据已保存会话的书签保留仍被引用的文件，并且只处理托管目录中的安全普通文件。无法确认引用、符号链接、硬链接或异常权限会保守保留。

普通刷新和连接期间不运行这项清理，避免影响仍使用旧私钥认证的标签。外部私钥不属于清理范围。

## 密码与口令的眼睛按钮

勾选将密码或私钥口令保存到钥匙串后，对应输入框带有眼睛按钮。默认隐藏，点击切换本次输入的显示状态；切换不改变输入内容。认证方式改变或输入区关闭后恢复隐藏。

编辑已有会话时，输入框不读取已存 Keychain 内容。留空仍按现有规则保留已保存的密码或口令；眼睛按钮只显示表单中本次输入的内容。

## 终端布局名称

布局菜单统一显示 **左右并列** 和 **上下堆叠**。两种方式仍将全部已打开的连接等分为一行或一列，不新建标签或连接。

## 验证方式

在仓库根目录运行：

```sh
sh Scripts/test.sh
```

托管私钥回归使用临时目录和生成的测试密钥，检查格式与权限、系统密钥解析、数据库隔离、保存回滚、重启恢复和启动清理，不读取个人私钥或写入用户 Keychain。

界面人工验证：

1. 新建私钥会话，选择粘贴；粘贴一份测试 OpenSSH 或 PEM 私钥后取消，确认未新增托管文件。
2. 再次粘贴并保存，重启应用后确认会话仍可使用；需要口令的密钥分别验证正确和错误口令。
3. 输入测试密码或口令，多次切换眼睛按钮，确认内容一致且继续输入仍作用于当前输入框。
4. 切换认证方式后确认内容和显示状态已重置。
5. 打开多个连接，确认布局菜单仅使用左右并列、上下堆叠两个名称，并保持原来的等分排列行为。
