# v0.3.0

本次新增批量执行命令和终端日志记录。

## 批量执行命令

- 通过 **⋯ 更多操作 → 批量执行命令** 展开独立命令栏，输入单行命令后按回车或点击**执行到全部**，发送到全部已连接的 SSH 标签，包括后台和分屏标签。
- 同一服务器的多个独立连接分别发送；等待认证、连接中和断线的标签会跳过，结果显示排队、跳过与队列已满的明细。
- 普通终端输入仍只影响当前会话；重连后不会自动重放旧命令，命令栏不保存历史。
- 批量栏打开时，新连接完成不会抢走正在输入的草稿焦点。

## 终端日志

- SSH 与本机终端默认自动记录，每个连接独立保留最近 **5 MB**，超限滚动删除较早内容。
- 设置中可关闭记录或调整为 **1–100 MB**，保存后立即生效。
- 终端内右键可开始、暂停和导出 UTF-8 文本日志；导出包含已保留内容和未换行尾部。
- vim 等程序进入备用屏幕时略过画面内容，仅记录进入、退出时间；正常断开、关闭与退出会完成日志收尾。
- 按反馈移除终端右上角的日志图标，状态与操作保留在右键菜单中。

从下方 **Assets** 下载 `.dmg`，打开后将 **DockShell.app** 拖到 **Applications（应用程序）** 安装。

批量命令应在各终端回到 shell 提示符后使用；“已排队”不表示远端已经执行成功。认证框中的密码、私钥口令和原始按键不会直接写入终端日志；服务器打印或回显的内容仍可能包含敏感信息。

继续保留会话管理、三种 SSH 认证、多标签与分屏、本机 Shell、SFTP 文件传输和即时字体设置。文件夹递归传输、端口转发等后续功能不包含在本版本中。
