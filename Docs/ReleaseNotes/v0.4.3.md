# v0.4.3

终端日志新增右键复制，暂停后重新开始记录时，导出和复制均从新的记录起点读取。

- 在“导出终端日志…”下方新增“复制终端日志”，可将本轮日志作为纯文本复制到剪贴板。
- 修复恢复记录后导出内容包含暂停前日志的问题。暂停期间仍可读取本轮已记录的内容，重新开始后仅导出或复制新一轮日志。
- 优化日志缓存，频繁暂停和开始共用原有分段与每连接容量。默认上限为 5 MB，可在设置中调整。
- 更新 README 的服务器管理、多标签与左右分屏截图，以及日志使用说明。

从下方 **Assets** 下载 `DockShell-0.4.3-arm64.dmg`，打开后将 **DockShell.app** 拖到 **Applications（应用程序）** 安装。
