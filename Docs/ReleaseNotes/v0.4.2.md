# v0.4.2

本次维护更新清理编译警告，并精简从源码启动时的构建范围。

- 普通启动只构建应用、SSH 辅助程序、资源编译器及其依赖；验证工具由测试脚本单独构建，继续使用增量缓存。
- 清理 SwiftTerm 缓冲区未使用返回值，以及验证工具中的旧辅助功能 API、弱引用和冗余表达式警告。
- 更新 SwiftTerm 最小补丁说明、构建标识和第三方声明；终端拷贝与绘制行为保持原有规则。
- 发布脚本移除已弃用的 `--skip-update`，保留依赖版本约束。
- CLT 兼容构建继续使用 native 引擎，并保留其弃用提示，待工具链更新后再迁移。
- 已有服务器配置、分组、私钥引用和 Keychain 凭据继续兼容；SSH / CSV 导入、SFTP、分屏、批量命令及日志等功能继续可用。

从下方 **Assets** 下载 `DockShell-0.4.2-arm64.dmg`，打开后将 **DockShell.app** 拖到 **Applications（应用程序）** 安装。
