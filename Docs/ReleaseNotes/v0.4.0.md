# v0.4.0

新增 SSH 配置导入和 CSV 批量创建，方便将已有服务器配置集中到 DockShell。

## SSH 配置导入

- 通过 **＋ → 导入 SSH 配置…** 或系统“会话”菜单打开，默认读取当前用户 `~/.ssh/config`，也可选择其他文件。
- 默认分组 `local-ssh-config`，可修改名称或选择已有分组。
- 支持具体 Host 别名、默认值继承、通配/排除规则、Include、引号与常用路径 token。
- 导入前可编辑名称、主机、端口、用户名和认证方式，勾选需要的会话；多把私钥要求明确选择一把。
- Match、跳板机及其他尚不支持的连接行为会明确提示，不执行配置中的命令。

## CSV 批量创建

- 通过 **＋ → CSV 批量创建服务器…** 打开文件或粘贴内容，默认分组 `csv-import`。
- 使用 `name,host,port,username,auth,key_path` 表头，支持 agent、password、key 三种认证配置。
- 支持 UTF-8 BOM、中文/emoji、引号与转义、CRLF，最多 1000 台服务器、2 MB。
- 预览中可修改字段、勾选与改名；字段错误显示明细，引号和列数错误标明源行。
- CSV 不填写密码或私钥口令；私钥路径引用外部文件，保存前重新检查格式、权限和可用性。

## 导入行为与文档

- 目标分组内同名及批内重复会话跳过并显示明细，修改名称后可导入；已有会话与凭据不覆盖。
- 新分组和本批会话在同一事务中保存，失败全部回滚；预览和取消不写入数据库，导入后不自动连接。
