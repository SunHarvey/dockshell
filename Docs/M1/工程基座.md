# M1：原生应用工程基座

历史里程碑记录；当前行为与完整文件以 [M2 文档](../M2/会话与凭据管理.md) 为准。

日期：2026-10-27。当前目录 `/Users/harvey/Documents/github-code/DeckShell`，按用户本轮要求直接在当前目录开发。产品名 DockShell；未自动重命名目录。

## 本轮范围

创建独立可构建的原生应用、五个分层模块、Swift 6 并发边界、原创主窗口、中英文资源、CLT 构建和标准应用打包。SSH 后端已选择系统 OpenSSH；持久化已选择系统 SQLite。

会话 CRUD、分组编辑、SQLite schema 与迁移、Keychain 实现留在 M2。SwiftTerm 与字体主题留在 M3。真实 SSH、主机指纹与凭据 helper 留在 M4/M5。本轮的空会话仓库不能保存数据，没有伪装成已完成持久化。

```text
DeckShell/

│   ├── CatalogCompiler/

├── Build/                         # 生成物，不提交
├── M0/                            # 保留独立历史探针
└── Docs/
```

本轮不引入第三方库。`CSQLite` 仅包含 module map 和 `<sqlite3.h>` 桥接，使用 SDK 头文件和系统动态库。OpenSSH 使用系统可执行文件；暂未创建正式进程适配器。SwiftTerm 1.19.0 的 SPM 接入在 M3 单独验证。

资源采用独立 `DockShellResources.bundle`，从已打包应用的 `Contents/Resources` 定位。没有生成的 `Bundle.module` 访问器，也没有返回源码目录的资源兜底。Catalog 编译器只支持本轮已使用的普通文本子集，遇到复数、占位符、缺译或未知字段直接失败。

## 验证方法

```sh
sh Scripts/test.sh
sh Scripts/run.sh zh-Hans
sh Scripts/run.sh en
```

在中英文窗口分别检查：

1. 原生侧栏、搜索框、工作区、连接状态与底部状态区可见。
2. 没有会话时展示明确空状态；搜索后显示无匹配提示。
3. 调整窗口大小、隐藏/显示侧栏，布局无裁切；最小尺寸 800 × 520。
4. 没有服务器连接、认证弹窗或持续刷新动画。
5. 退出后可重新打开 `.app`，文案仍正确。

UI 构造检查（需要图形桌面；仅验证视图创建和布局，不能代替人工界面检查）：

```sh
DOCKSHELL_UI_SMOKE=1 sh Scripts/test.sh
```

`test.sh` 会暂时将 `.build/app` 移到同级临时目录，验证复制到随机临时目录的应用资源与签名，再通过退出 trap 还原。测试期间不要并行运行另一个构建。脚本不会移动源代码或 M0 探针。

## 验证边界

- 自动检查不要求 XCTest / Swift Testing，因此不受当前 CLT 宏插件缺口影响。
- `.app` 使用本地 ad-hoc 签名，不是 Developer ID 签名或公证发行包。
- 系统依赖版本随 macOS 改变，不能用当前宿主版本替代 macOS 14 运行证据。
- M1 没有实际终端，不能据此宣称 IME、vim、背压或断线恢复通过。
- SwiftData 不再是获选持久化方案；原宏插件失败记录保留作历史证据。

## 2026-10-27 实测结果

宿主 macOS 27.0.1 / arm64，Apple Swift 6.4、SDK 27.0；使用 SwiftPM 当前默认 `swiftbuild`，M1 不需要已弃用的 native 构建方式。

| 检查 | 结果 |
|---|---|
| Debug 构建与 `test.sh` | 退出 0 |
| Release 构建与 `test.sh release` | 退出 0 |
| Catalog Unicode、引号、反斜线、换行往返 | 通过 |
| 未支持格式、缺译、未完成译文等 8 项负向输入 | 全部拒绝 |
| 中英文资源与区域语言匹配 | 22 个类型化键 × 2 种语言通过 |
| 系统 SQLite 链接 | 3.54.0；无 Homebrew 运行依赖 |
| 系统 SSH 检查 | OpenSSH 10.3p1 / LibreSSL 3.3.6；只运行 `ssh -V` |
| SwiftUI / AppKit UI smoke | 1080 × 720 视图创建和布局通过 |
| 桌面实际窗口 | 已打开中文、英文窗口；中文/emoji 搜索空状态、侧栏折叠和恢复通过 |
| 资源搬迁 | 隐藏原 `.build/app`，临时目录副本的资源查找与签名检查通过，退出后还原构建目录 |
| Mach-O 最低版本标记 | Debug / Release 的 `minos` 均为 14.0；不代表 macOS 14 已运行 |
| 动态链接路径 | 当前应用只链接系统框架与系统动态库 |

当前 CLT 默认构建器会输出指向缺失 `Developer/Library/Frameworks` 等搜索目录的链接警告；上述构建仍成功，未增加虚构目录或外部库来掩盖警告。工具沙盒曾阻止 Release 的 dSYM 生成以及 GUI 启动；在正常桌面权限下，标准构建、测试和运行命令均已成功。没有禁用 Gatekeeper 或其他系统安全功能。

真实 macOS 14、最小窗口人工检查、深色外观，以及后续终端和网络验收仍按相应阶段完成。
