# v0.2.0

本次主要新增 SFTP 文件浏览与传输。

- 终端右侧可收起的远程文件面板，每个标签保留独立目录，支持路径导航、名称筛选和隐藏文件显示。
- 普通文件多选上传、下载及传输队列，显示进度并支持取消；传输使用独立连接。
- 同名上传自动覆盖；重复下载自动添加 ` (1)`、` (2)` 等编号，保留本机原文件。
- 字体、字号、配色和滚屏历史保存后立即应用到当前与后台终端，无需重连。
- 精简顶部工具栏，移除按钮外层玻璃背景，保留悬浮提示；支持多标签、左右并列与上下堆叠。

从下方 **Assets** 下载 `.dmg`，打开后将 **DockShell.app** 拖到 **Applications（应用程序）** 安装。

当前支持普通文件传输，文件夹递归传输与断点续传留待后续版本。
