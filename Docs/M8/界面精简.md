## 操作入口

右上角显示连接状态的下拉菜单负责**当前面板**的连接操作。分屏时先点击目标面板，再展开该菜单；菜单内显示目标会话名称和非敏感连接地址，便于核对操作对象。

| 状态 / 操作 | 行为 |
|---|---|
| 正在连接 | “取消”结束该面板的连接和待答认证 |
| 已连接 | “断开连接”只结束该面板的 SSH 连接，保留面板 |
| 已断开 / 失败 | “重新连接”按当前设置重新建立该面板连接 |
| 菜单“关闭终端” | 只关闭当前面板；还有另一面板时，另一连接继续运行并铺满 |
| 标签页上的 × | 关闭该标签内全部面板与连接 |

没有远程面板时，连接操作菜单禁用；保留的断线面板仍可手动重连。菜单操作使用展开时对应的面板身份，断开和重连前检查该实例仍由工作区持有。

主机指纹确认、密码 / 私钥口令表单、连接错误、睡眠唤醒检查和字体延后提示继续按需显示。终端底部的字符网格及工作区底部状态栏保留。
