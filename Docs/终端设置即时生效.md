# 终端设置即时生效

2026-10-30，用户同意制作 SwiftTerm 最小补丁，验证通过后接入。此前 M4 / M5 在连接期间冻结字体的策略由本次变更取代。

## 当前行为

在设置中修改字体、字号、主题或滚屏历史，点击保存后，已打开的 SSH 终端和本机 Shell 立即更新，包括后台标签和分屏。连接与终端视图保持原有实例，不重新认证，不重启 Shell。字体指标变化后，以实际行列数同步 PTY 的窗口尺寸，让 vim / top 处理正常的 SIGWINCH。

默认历史仍为 10000 行，可设 1000–100000 行；降低上限会按原策略丢弃超限的旧历史。字体修改保留服务器当前的前景、背景和光标颜色；用户明确切换主题时，按新主题更新颜色。

顶部继续使用紧凑标题栏；右侧工具栏容器单独保持 36pt 高、常规控件尺寸和左右各 8pt 留白，避免紧凑样式同时压缩按钮区域。

## 补丁与依赖

SwiftTerm 上游 SPM 地址为 `https://github.com/migueldeicaza/SwiftTerm.git`，固定基于 **1.19.0** / `464df5207fc2432e16c9a23abe538187196daf5f`。构建标识为 **1.19.0+dockshell.1**，通过 [本地 SPM 包](../Vendor/SwiftTerm/Package.swift) 接入。

唯一上游行为补丁修改 `resetFont()`，用普通窗口缩放路径代替会额外 soft-reset 的公共 resize 路径。原版公共 resize API 的行为保持原样。本地包收录上游库源码、许可证、原 manifest、明确的 diff 与固定构建元数据；不依赖开发机的 SwiftPM 缓存，不需要远端个人 fork。来源、文件摘要与升级要求见 [UPSTREAM.md](../Vendor/SwiftTerm/UPSTREAM.md)。

原上游命令工具及文档插件不进入本地包，应用不再解析 ArgumentParser 等工具依赖。没有新增第三方库；SwiftTerm 的 MIT 版权声明继续随应用分发。

## 验证入口

```sh
sh Scripts/test-terminal-settings.sh
sh Scripts/test-terminal-settings.sh release
DOCKSHELL_UI_SMOKE=1 sh Scripts/test.sh
```

专项在独立设置仓库、合成 SSH 通道和真实隔离本机 PTY 中检查：

- 连续切换字体 / 字号，保留全屏缓冲、光标显示与键盘模式、origin / wrap / insert、鼠标和粘贴模式、SGR 属性及服务器颜色。
- 中文、emoji、输入法 marked text 和单次提交；字体变化后的光标键编码。
- 保存设置后，当前与后台标签更新字体、主题、历史与通道尺寸，终端和连接实例不变。
- 固定 `/bin/zsh -f -i` 使用临时 HOME / ZDOTDIR，运行系统真实 vim / top；vim 在变更字体后继续编辑中文，并通过自身 `&columns` / `&lines` 核对 PTY 尺寸，top 退出后继续输入 shell 命令。

CI 与 Release 工作流包含此专项。真实中文输入法候选窗口、macOS 14 实机及个人 Linux 会话的手工操作仍需人工确认；上述本机 PTY 和合成 SSH 检查不冒充该环境的实测。本轮不打版本标签、不发布 Release。

本轮本机结果：Debug 原生回归、Debug / Release 默认回归与应用搬迁、两种构建的字体专项、Release 的真实回环 SSH/SFTP 集成通过。另核对了全部 84 个上游库文件，除字体缩放补丁外均保持原样；发布脚本守卫及两个工作流的 YAML 解析通过。远端 CI 状态以对应提交的 Actions 运行记录为准。

手工检查：运行新版应用，打开两个 SSH 标签或分屏，在其中运行 vim；打开设置并修改字体 / 字号后保存。确认所有终端文字变化、vim 正常重绘和方向键可用，再检查本机终端与 top。
